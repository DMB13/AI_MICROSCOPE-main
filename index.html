Project Overview

🎯 Project Objective

In resource-constrained clinical settings, identifying bacterial pathogens traditionally takes 48 to 72 hours through culture methods. This delay often leads to empirical prescribing of broad-spectrum antibiotics, contributing to antimicrobial resistance.

AI Microscope introduces an Offline AI-Assisted Workstation designed specifically for the Microbiology Laboratory at Mbeya Regional Referral Hospital (MRRH), reducing diagnostic time from days to seconds.

🏥 Clinical Impact

  • Faster diagnosis enabling timely, targeted antibiotic therapy
  • Reduced antibiotic resistance through precision medicine
  • Improved patient outcomes and reduced hospital stay
  • Support for low-resource clinical environments

🔬 Scientific Innovation

Utilizes a deep learning model (EfficientNetV2M) trained on the Digital Bacterial System (DiBaS) dataset to classify 34 bacterial species with explainable AI (Grad-CAM) visualization.

Technical Specifications

🤖 AI Model Architecture

  • Base Architecture: EfficientNetV2M
  • Framework: TensorFlow 2.18.1 with Keras 3.x
  • Input Resolution: 224x224 RGB images
  • Output Classes: 34 bacterial species
  • Model Parameters: 105.7M
  • Model File Size: ~1.2GB (best_clinical_rugged_1777619657.keras)

💻 Software Requirements

  • Python 3.11+
  • TensorFlow 2.18.1
  • OpenCV (Computer Vision)
  • CustomTkinter (UI Framework)
  • SQLite3 (Database)
  • Pillow/PIL (Image Processing)
  • NumPy (Numerical Computing)

🛠️ System Architecture

Layered MVC Architecture:

  • Controllers: Camera, Diagnosis, Export operations
  • Views: Control Wing, Primary Viewport, Intelligence Wing
  • Models: Database operations and data models
  • Services: Inference and clinical record management

🏥 Clinical Specifications

  • Confidence Threshold: 90% minimum
  • Processing Time: Under 5 seconds per sample
  • Dataset: Digital Bacterial System (DiBaS) with clinical validation
  • Explainability: Grad-CAM heatmap visualization
