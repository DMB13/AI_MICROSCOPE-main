## Overview

The AI Microscope is your intelligent assistant for bacterial identification. It uses advanced AI to analyze microscope images and identify bacterial species with high accuracy.

**Key Features:**
- 📷 Real-time camera capture
- 🔬 AI-powered diagnosis
- 📊 Confidence scoring
- 🗺️ Heatmap visualization
- 💾 Automatic record saving
- 📄 Report generation

---

## Capturing Images

### Using the Camera

1. **Connect your microscope camera** to the computer
2. The system automatically detects available cameras
3. Select the correct camera from the dropdown menu
4. Adjust brightness and contrast if needed
5. Click **📷 Capture** to take the image

### Uploading Existing Images

1. Click the **📁 Upload Image** button
2. Browse to your image file
3. Select the image and click **Open**
4. The image will appear on your screen

### Image Quality Tips

**For Best Results:**
- Ensure the image is in focus
- Use adequate lighting
- Avoid motion blur
- Clean the microscope lens regularly

**Supported Formats:**
- JPG, JPEG, PNG
- Recommended resolution: 1280x720 or higher

## Running Diagnosis

### How It Works

1. The AI analyzes the captured image
2. It identifies the most likely bacterial species
3. It provides a confidence score
4. It generates a heatmap showing focus areas

### Running a Diagnosis

1. **Capture or upload** an image
2. Click the **🔬 Run Diagnosis** button
3. Wait 5-10 seconds for analysis
4. Review the results

### Understanding Results

**Species Identification:**
- Shows the predicted bacterial species
- Includes scientific name
- Shows confidence percentage

**Confidence Score:**
- **90%+**: Highly reliable
- **70-89%**: Reliable, consider confirmation
- **Below 70%**: Confirm with additional tests

**Heatmap:**
- Red areas show where AI focused most
- Helps verify the AI is looking at the right features

## Managing Records

### Viewing Records

1. Click the **📋 Records** tab
2. Browse through your diagnosis history
3. Click any record to view details

### Searching Records

1. Use the **Search** box
2. Enter Patient ID or date
3. Results appear instantly

### Deleting Records

1. Select the record you want to delete
2. Click the **🗑️ Delete** button
3. Confirm the deletion

**Note:** Deleted records cannot be recovered.

## Settings

### Camera Settings

- **Camera Index**: Select which camera to use
- **Resolution**: Choose image quality (640x480 to 2560x1440)
- **Frames Per Second**: Adjust capture speed
- **Auto-detect**: Let the system find cameras automatically

### Image Adjustments

- **Brightness**: Make images lighter or darker
- **Contrast**: Adjust the difference between light and dark
- **Saturation**: Change color intensity
- **Sharpness**: Make edges clearer
- **Auto-enhance**: Let the system optimize automatically

### AI Settings

- **Confidence Threshold**: Set minimum confidence for clinical use
- **Show Confidence**: Display confidence scores on screen
- **Enable Grad-CAM**: Show heatmap visualization
- **Prediction Timeout**: Maximum time to wait for results

### Clinical Settings

- **Require Patient ID**: Force entry of patient ID before saving
- **Auto Timestamp**: Automatically add date and time
- **Enable Audit Log**: Track all user actions

## Exporting Reports

### Export Formats

**PDF Report:**
- Professional medical document
- Includes image, diagnosis, and metadata
- Suitable for patient records

**CSV Export:**
- Spreadsheet format
- Suitable for data analysis
- Can be opened in Excel

### How to Export

1. Go to the **Records** tab
2. Select the records you want to export
3. Click the **📤 Export** button
4. Choose your preferred format
5. Select save location
6. Click **Save**

### Export Options

- **Include Images**: Add original images to export
- **Include Heatmaps**: Add heatmap visualizations
- **Auto-export**: Automatically export new records

## Troubleshooting

**Camera not working?**
- Check camera connection
- Try a different USB port
- Restart the application

**Diagnosis taking too long?**
- Check your internet connection
- Close other applications
- Restart the computer

**Results seem incorrect?**
- Ensure image quality is good
- Verify sample preparation
- Consult with supervisor
